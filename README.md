# قاب من

اپلیکیشن اندروید واقعیت افزوده: با باز کردن برنامه، دوربین مستقیم باز می‌شود. وقتی دوربین را روی عکسِ قاب بگیرید، فیلم **دقیقاً روی همان عکس** پخش می‌شود و با حرکت گوشی، همراه عکس جابه‌جا می‌شود (Track).

## عکس و فیلم
عکس و فیلم داخل خود برنامه قرار دارند:
- `app/src/main/assets/target.jpg` — عکسی که باید شناسایی شود
- `app/src/main/assets/video.mp4` — فیلمی که روی عکس پخش می‌شود (از وسط برش داده شده تا هم‌نسبت عکس باشد)

برای عوض کردن، همین دو فایل را با همین نام جایگزین کنید و در `app/build.gradle.kts` عدد `versionCode` را یکی زیاد کنید.

## موتور ردیابی
بدون نیاز به ARCore / Google AR — روی هر گوشی اندروید ۷ به بالا با دوربین:
OpenCV با ویژگی‌های ORB عکس را پیدا می‌کند و با جریان نوری فریم‌به‌فریم دنبالش می‌کند.
خط کوچک پایین صفحه (frames / matches) برای عیب‌یابی است: اگر frames بالا می‌رود دوربین کار می‌کند،
و matches نشان می‌دهد چند نقطهٔ عکس دیده می‌شود (بالای ۱۸ یعنی عکس تشخیص داده می‌شود).

## ساخت APK
- **GitHub:** همهٔ فایل‌ها را در مخزن آپلود کنید؛ در تب Actions، APK در بخش Artifacts ساخته می‌شود.
- **Android Studio:** پوشه را Open کنید و Run بزنید.
- **خط فرمان:** `./gradlew assembleDebug`

## نکات استفاده
- عکس چاپی را صاف و در نور کافی قرار دهید؛ چاپ مات بهتر از براق است.
- گوشی را حدود ۳۰ تا ۶۰ سانتی‌متر از عکس نگه دارید و ابتدا روبه‌روی آن بگیرید.
- دکمهٔ پایین صفحه صدای فیلم را قطع/وصل می‌کند.
